# 从 CAD 坐标文件导入贴片位

入口：文件菜单"导入贴片坐标..."，或单板页的导入按钮（导入到所选单板）。实现在 `src/core/cadimport/`（读取与转换）和 `src/app/cadimport/`（对话框的选项与预览）。

导入只改程序，不改格式：结果是普通的贴片位、元件、封装，`formatVersion` 不变。

## 1. 读取文件

### 编码

UTF-8（有无 BOM 均可）、带 BOM 的 UTF-16 / UTF-32；都不是时按 GB18030（GBK 的超集）解码，这是中文 Windows 上 Altium 等工具保存"ANSI"文件的编码。

### 分隔符和表头

坐标文件都是文本表格，差别在分隔符、引号、注释行和表头位置：

| 来源 | 分隔符 | 表头 |
|---|---|---|
| KiCad `.pos` | 空格 | 注释行 `# Ref Val Package PosX PosY Rot Side` |
| KiCad `.csv` | 逗号，带引号 | 第一行 |
| Altium Pick Place `.csv` | 逗号，带引号 | 前面有十几行文件信息 |
| 嘉立创 / EasyEDA CPL | 逗号或制表符 | 第一行，坐标带单位如 `12.7mm` |
| 其他 | 逗号、制表符、分号、空格 | 可能没有表头 |

自动识别：对每种分隔符，在前 60 行里找能认出位号、X、Y 三列的那一行作表头，取认出字段最多的分隔符。找不到表头时不设表头，取"等宽行最多 → 能读成数字的字段最多 → 列最多"的分隔符；表头前、或无表头时第一条等宽数据行之前的文字算说明行，不当数据。

双引号内的分隔符不分列，`""` 表示一个引号。以 `#` 或 `//` 开头的行是注释。

对话框里分隔符、表头行（行号，"无"表示没有表头）都可以手动指定。改分隔符后重新找表头。

### 列

表头名大小写、空格、`-`、`_`、括号里的单位都忽略后比较。同一字段有多列时按优先级取：

| 字段 | 识别的表头（优先级从高到低） | 必选 |
|---|---|---|
| 位号 | Designator / Ref / RefDes / Reference / 位号 / 标号；其次 Part / Name | 是 |
| X、Y | Center-X / Mid X / 中心X；其次 X / PosX / Ref X / 坐标X；最后 Pad X | 是 |
| 角度 | Rotation / Rot / Angle / Orientation / 角度 | 否，默认 0 |
| 面 | Side / Layer / T/B / 面 / 层 | 否，默认顶面 |
| 封装 | Footprint / Package / Pattern / 封装 | 否 |
| 值 | Value / Val / 值；其次 Comment（Altium 的值在 Comment 列） | 否 |

每个字段的列都可以在对话框里改；没有表头时必须手动选位号、X、Y。

### 单位

先看 X / Y 列表头里的单位（`Center-X(mil)`），再看说明行（KiCad `## Unit = mm`、Altium `Units used: mil`），都没有时按 mm。可手动改为 mm / mil / inch。单个数值带单位后缀（`12.7mm`、`500mil`）时以后缀为准。

数值的小数点可以是 `.`；没有 `.` 且只有一个 `,` 时，`,` 视为小数点。

### 面

顶面：`top`、`T`、`TopLayer`、`F.Cu`、`front`、`顶面`、`顶层`、`正面` 等。底面：`bottom`、`B`、`BottomLayer`、`B.Cu`、`back`、`底面`、`底层`、`背面` 等。空白取顶面，其他值是错误。

## 2. 坐标转换

```
板坐标 = 文件坐标（换算成 mm） − 板原点
角度   = 文件角度，归一化到 [0, 360)
```

- **板原点**：板左下角（顶视）在文件坐标里的位置，单位 mm，默认 0。CAD 的坐标原点不在板左下角时填这里。导入后有贴片位落在板外时，预览和结果都会提示检查原点。
- **底面元件**：坐标按文件原样导入，不镜像，与程序格式"底面坐标仍按从顶面看给出"一致。KiCad、Altium 默认导出的就是顶视坐标。
  - **未验证**：还没有用真实的 KiCad / Altium 底面导出文件核对过角度约定。KiCad 导出时若勾选了"底面元件 X 取负"，X 会是负数，需要先不勾选再导出。
- 封装的零度方向在不同 CAD 库之间可能不同，导入不做补偿；需要时以后在封装上加角度偏移。

## 3. 元件匹配

有效行按（封装名, 值）分组，每组对应一个元件。默认建议：

1. 已有元件的封装 id 等于封装名、值相同 → 用该元件；
2. 已有元件的 id 等于导入时会生成的 id（见下）→ 用该元件（同一文件再次导入不会重复建元件）；
3. 否则新建元件；已有封装的 id 等于封装名时用该封装，否则新建封装。

每组都可以在"元件匹配"页改成已有元件，或新建元件并指定已有封装。

新建元件的 id 为 `封装名-值`；只有其中一个时用它；都没有时为 `PART`。新建封装的 id 为封装名，空时为 `PKG`。id 已被占用时加 `-2`、`-3`……。同一封装名的多组共用一个新封装。

**新建封装的尺寸是占位值 1 × 1 × 1 mm**（长、宽、高必须大于 0），取放参数为默认值。导入结果会列出新建的封装，需要到封装页填写真实数据。高度不对会影响取放下压，以后在运行前校验里要对此报警（待办）。

## 4. 写入单板

| 方式 | 文件中的位号已在板上 | 文件中的新位号 | 板上有、文件中没有的位号 |
|---|---|---|---|
| 合并（默认） | 更新元件、坐标、角度、面，保留"贴装"开关 | 追加到末尾 | 保留 |
| 替换 | 同左 | 按文件顺序 | 删除，并删除各子板实例对它的跳过设置 |

替换后贴片位的顺序与文件一致。替换前若会删除贴片位，先弹窗确认。

文件没有 DNP 列，所以"贴装"开关只对新位号设为开，已有位号保持原样。

有错误的行（缺位号、X / Y 不是数字、无法识别的面、位号与前面的行重复）不导入，在预览里列出原因；其余行照常导入。

整次导入是**一个撤销步骤**，经过 `ProgramDocument::edit()`：先在副本上执行，副本通过 `ProgramValidator` 才替换程序。单板已与文件一致时不能导入。
